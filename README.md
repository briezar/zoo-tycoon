# Wildlands Zoo Builder

A narrative-driven isometric zoo builder made in Unity. You play as a young heir returning to your late father's overgrown estate, clearing debris, constructing habitats, and building your own zoo from the ground up.

## Overview

The game opens with a cinematic introducing the player to their inherited land before handing over control. From there the loop is simple: clear the overgrown estate, spend resources to build habitats, and attract animals to grow your zoo. Story quests guide the experience as the zoo comes to life.

---

## Features

### Gameplay

| | |
|---|---|
| Cinematic Camera | In-engine cutscenes triggered throughout gameplay |
| Player Movement | Click to move, double-click to run, hold to continuously follow the cursor |
| Story / Quest System | Structured objectives that guide the player through the experience |
| Dialogue System | Story dialogue that plays as quests progress |
| Building & Placement | Construct and place habitats and structures across the estate |
| Overworld Interaction | Auto-opening doors on proximity, interact with animals and environment |
| Isometric Camera | Classic isometric gameplay |
| Progression System | Unlock new animals, habitats, and story beats as the zoo grows |
| Resource System | Manage Gold, Energy, and Gems earned throughout the game |

### Technical

| | |
|---|---|
| 3D Object Outline | Per-object outline using URP Renderer Feature and Rendering Layers |
| Responsive UI | Scales cleanly across resolutions |
| Static Batching | Environment objects batched at runtime to reduce draw calls |
| Post-Processing | URP post-processing with color grading, bloom, and vignette |
| Custom Editor Tooling | Unity Editor extensions to speed up level design and content placement |
